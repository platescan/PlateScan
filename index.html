How XP works

Every meal logged earns 10 XP (up to 5 a day), plus 5 more when you scan it with the camera. Hitting your protein target is worth 25, landing within 10% of your calorie target (with 2+ meals logged) is worth 25, and a weigh-in is worth 10. Logging on back-to-back days adds a streak bonus of 2 XP per streak day, up to 20. Each level needs 50 more XP than the one before.

Home & Lock Screen widget

Shows your streak and whether you've logged today. Uses the free Scriptable app.

How to add it
  1. Install Scriptable (free) from the App Store.
  2. Tap Copy widget script above.
  3. Open Scriptable, tap +, paste, and name the script PlateScan.
  4. Home Screen: press and hold an empty spot → Edit → Add Widget → Scriptable → small or medium → Add. Tap the widget, set Script to PlateScan.
  5. Lock Screen: press and hold the Lock Screen → Customize → Lock Screen → tap the widget area → Scriptable. Tap the new widget and set Script to PlateScan.
